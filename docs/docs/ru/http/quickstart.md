# Быстрый старт

## Описание метода и результата.

Каждый http метод в `retejo` наследуется от базового метода `HttpMethod`.

```py linenums="1"
{!> docs_src/http/quickstart.py [ln:13-23] !}
```

1. Body - является маркером, который указывает куда соотнести поле при отправке запроса.

HttpMethod является дженериком, который принимает тип ответа.

Им может быть `dataclass`, `pydantic`, `msgpec`, `attrs` модель, `None` для "никакого" ответа и `Any` для сырого ответа.
