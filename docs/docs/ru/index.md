# Retejo - ретейо

Простая, но мощная библиотека с приятным API для создания http, и не только, клиентов.

## Возможности

1. Полностью типизированная библиотека.

2. Гибкая конфигурация фабрик за счет **adaptix**.

3. Декларативное описание методов

    ??? Пример
        ```py linenums="1"
        {!> docs_src/index.py [ln:13-21] !}
        ```

4. Декларативное описание клиента

    ??? Пример
        ```py linenums="1" hl_lines="5 9"
        {!> docs_src/index.py [ln:24-37] !}
        ```

        1. Преобразование атрибутов вида camelCase в lower_case.

        2. Привязывание метода к клиенту.
